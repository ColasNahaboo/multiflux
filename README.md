# Miniflux RSS Companion
![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)

Miniflux RSS Companion is a lightweight Chrome/Chromium extension that displays the unread item count from your Miniflux RSS server and provides quick, one-click access to the Miniflux web interface. It is a fully independent Manifest V3 implementation designed for modern Chromium-based browsers.

## Features
- Toolbar badge displaying unread item count  
- Click to open or focus an existing Miniflux tab  
- Supports Fresh, All, and Custom views  
- Configurable refresh interval  
- Optional “open in new tab” behavior  
- All processing occurs locally in the browser  
- Compatible with any self-hosted Miniflux installation  

## Privacy Policy
Miniflux RSS Companion does not collect, store, transmit, or share personal data.

- All extension functionality runs locally in the user’s browser  
- User preferences (server URL, refresh interval, view selection) are stored using Chrome’s extension storage and may be synced by Chrome across the user’s devices  
- The extension communicates solely with the Miniflux server URL provided by the user  
- No analytics, tracking, advertising, cookies, or third-party requests  
- No remote code is loaded or executed
