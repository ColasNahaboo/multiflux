# Miniflux RSS Companion
![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)


Miniflux RSS Companion is a lightweight Chrome/Chromium extension that displays the unread count from your Miniflux RSS server and provides quick, one-click access to your Miniflux RSS web interface. This is a fully independent Manifest V3 implementation designed for modern browsers.

## Features

- Toolbar badge showing unread item count  
- Click to open or focus your Miniflux RSS tab  
- Supports Fresh, All, and Custom views  
- Configurable refresh interval  
- Optional “open in new tab” behavior  
- All processing happens locally  
- Works with any self-hosted Miniflux RSS installation  

## Privacy Policy

Miniflux RSS Companion does **not** collect, store, transmit, or share any personal data.  
All extension functionality occurs locally in the user's browser.

- The extension stores only user preferences (server URL, refresh interval, view selection) using Chrome's local extension storage.  
- The extension communicates **only** with the Miniflux RSS server URL the user provides.  
- No analytics, tracking, advertising, or cookies are used.  
- No remote code is loaded or executed.  
- No data is sent to third parties.
