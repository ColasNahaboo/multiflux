# Miniflux RSS Companion — Privacy Policy
**Last updated: January 2025**

Miniflux RSS Companion does **not** collect, store, transmit, or share any personal data.  
All functionality is performed locally within the user’s browser.

## What the extension does
- Displays unread item counts retrieved directly from the user’s Miniflux RSS server  
- Stores the user's configuration settings (server URL, refresh interval, view preference) using Chrome’s local extension storage  
- Communicates only with the Miniflux RSS server URL the user provides  

## What the extension does NOT do
- Does not collect personal information  
- Does not store data on external servers  
- Does not transmit data to third parties  
- Does not use analytics or tracking technologies  
- Does not use cookies  
- Does not load or execute remote code  
- Does not access any websites other than the Miniflux RSS server specified by the user  

## Data Storage
All settings are stored locally on the user's device using Chrome’s extension storage API.  
No data leaves the device, and nothing is shared externally.

## Permissions
The extension requests the following browser permissions:
- **storage** — to save user preferences locally  
- **alarms** — to periodically refresh the unread count  
- **tabs** — to open or focus the user’s Miniflux RSS tab  
- **host permissions** — to connect only to the Miniflux RSS server URL the user enters  

These permissions are strictly required for the extension’s single purpose and are not used for any other functionality.
