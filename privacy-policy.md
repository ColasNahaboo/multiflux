# Miniflux RSS Companion — Privacy Policy

Miniflux RSS Companion does **not** collect, store, transmit, or share personal data.

All extension functionality runs locally in the user’s browser. Configuration settings are stored using Chrome’s extension storage and may be synced by Chrome across the user’s devices.

## What the extension does
- Displays unread item counts retrieved directly from the user’s Miniflux RSS server  
- Stores user configuration settings (server URL, refresh interval, view preference) using Chrome’s extension storage  
- Communicates only with the Miniflux RSS server URL explicitly provided by the user  

## What the extension does NOT do
- Does not collect personal information  
- Does not operate external servers  
- Does not transmit data to third parties  
- Does not use analytics, tracking technologies, or advertising  
- Does not use cookies  
- Does not load or execute remote code  
- Does not access any websites other than the Miniflux RSS server specified by the user  

## Data Storage
Configuration settings are stored using Chrome’s extension storage API.  
Any syncing of settings is handled entirely by Chrome according to the user’s browser and account configuration.

## Permissions
The extension requests the following browser permissions:
- **storage** — to save user preferences  
- **alarms** — to periodically refresh the unread item count  
- **tabs** — to open or focus the user’s Miniflux RSS tab  
- **omnibox** — to enable quick search access from the browser address bar  
- **host permissions** — to connect to the Miniflux RSS server URL provided by the user  

These permissions are required solely to provide the extension’s stated functionality and are not used for any other purpose.
